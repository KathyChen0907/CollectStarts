# Hero Stars 英雄集星基地

單一孩子使用的繁體中文集星網頁 App，針對 iPad 觸控介面設計。提供紅金能量、紅藍蜘蛛、星盾隊長三種主題，以及任務加星、自訂鼓勵、獎勵兌換、紀錄撤銷與家長 PIN。

## 開發

需要 Node.js 22 或以上，沒有外部套件依賴。

```sh
npm run dev
npm run check
```

預設 port 3000，可透過 PORT 調整。伺服器提供靜態檔案；正式使用請部署到 HTTPS 靜態網站主機。在 iPad Safari 開啟正式網址，使用「分享 → 加入主畫面」。本地開發可透過 localhost 使用 PIN；遠端使用需 HTTPS。

## 資料與限制

資料保存於目前瀏覽器的 localStorage，不會自動同步或備份，清除網站資料會遺失紀錄。初次操作建立家長 PIN，忘記 PIN 無自動復原機制。PIN 以帶隨機 salt 的 SHA-256 保存，用於防止孩子誤操作，不構成帳號驗證或抵擋能存取瀏覽器資料的使用者。沒有內建預設 PIN 或示範星數。此版本提供網站 manifest 與主畫面圖示，未提供離線 service worker。三種主題使用原創幾何圖形與配色，不含電影角色圖像。
