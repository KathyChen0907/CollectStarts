# Hero Stars 英雄集星基地

單一孩子使用的繁體中文集星網頁 App，針對 iPad 觸控介面設計。提供紅金能量、紅藍蜘蛛、星盾隊長三種主題，以及任務加星、自訂鼓勵、獎勵兌換、紀錄撤銷與項目管理。

## 開發

需要 Node.js 22 或以上，沒有外部套件依賴。

```sh
npm run dev
npm run check
```

預設 port 3000，可透過 PORT 調整。伺服器提供靜態檔案；正式使用請部署到 HTTPS 靜態網站主機。在 iPad Safari 開啟正式網址，使用「分享 → 加入主畫面」。

## 資料與限制

資料保存於目前瀏覽器的 localStorage，不會自動同步或備份，清除網站資料會遺失紀錄。所有操作皆可直接使用，無需輸入 PIN。沒有內建示範星數。此版本提供網站 manifest 與主畫面圖示，未提供離線 service worker。三種主題使用原創幾何圖形與配色，不含電影角色圖像。

## 管理項目

點「家長設定」後，可進入「管理集星項目」或「管理兌換項目」。兩者皆可新增、編輯、刪除項目及調整名稱、圖示與星數；集星項目另可修改說明。刪除前需要確認。修改只影響後續操作，不會重算或刪除歷史紀錄。舊版資料會自動補上預設集星項目，保留原有餘額、獎勵及紀錄；自行刪除所有項目後，重新整理也不會恢復預設項目。

## 日常任務與兌換規則

`daily-plan.js` 使用文件的任務條件作為全年適用的日常設定，依目前裝置的星期自動顯示，不限制月份或日期，也不需要等到 11 月。一般平日 10 項各 1 星；週五 9 項，其中主動行為 2 星；週六 10 項，不含睡前項目；週日 10 項，包含 21:40 前就寢。預設每天合計 10 星。切回 App 或跨日後會自動更新。

兌換獎勵依使用者提供的七項清單，從 20 星故事到 300 星玩具。初次套用備份舊任務與獎勵設定於 previousMissionConfig、previousRewardConfig，保留所有餘額與歷史紀錄。套用後仍可管理項目，更新不覆蓋已調整的項目。本次取消月份限制沿用原本的項目 ID 與設定版本，不會重新匯入或重設資料。新建任務每天顯示。

文件任務版 v2 依 Word 的列順序顯示當日任務，靜態檔案附版本參數避免沿用前版腳本。首次載入 v2 會重新套用文件任務與七項獎勵，原設定備份至 previousMissionConfig / previousRewardConfig，保留餘額與歷史。頁尾可確認「文件任務版 v2」。此版已以瀏覽器逐日比對 Word 的全部 30 張表格，檢查名稱、完整條件、星數及順序。

## 平日／假日挑戰版 v3

以使用者最新截圖的兩張表為準：平日採起床穿衣、書包餐袋等 10 項；假日採整理、用餐、家事、閱讀、作業等 10 項，兩組皆包含睡前目標，每項 1 星。週一至週五預設平日、週六日預設假日，可從首頁切換，當天選擇會保存，隔天重新依星期判定。此規則取代原文件的週五與週六特殊版本。既有餘額與紀錄不重算，項目管理仍可使用。
