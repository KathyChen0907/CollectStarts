# Hero Stars 英雄集星基地

單一孩子使用的繁體中文集星網頁 App，針對 iPad 觸控介面設計。提供紅金能量、紅藍蜘蛛、星盾隊長三種主題，以及任務加星、自訂鼓勵、獎勵兌換、紀錄撤銷與項目管理。

## 開發

需要 Node.js 22 或以上，沒有外部套件依賴。

```sh
npm run dev
npm run check
```

預設 port 3000，可透過 PORT 調整。伺服器提供靜態檔案；正式使用請部署到 HTTPS 靜態網站主機。在 iPad Safari 開啟正式網址，使用「分享 → 加入主畫面」。

## 資料與限制

資料保存於目前瀏覽器的 localStorage，不會自動同步或備份，清除網站資料會遺失紀錄。所有操作皆可直接使用，無需輸入 PIN。沒有內建示範星數。此版本提供網站 manifest 與主畫面圖示，未提供離線 service worker。三種主題使用原創幾何圖形與配色，不含電影角色圖像。

## 管理項目

點「家長設定」後，可進入「管理集星項目」或「管理兌換項目」。兩者皆可新增、編輯、刪除項目及調整名稱、圖示與星數；集星項目另可修改說明。刪除前需要確認。修改只影響後續操作，不會重算或刪除歷史紀錄。舊版資料會自動補上預設集星項目，保留原有餘額、獎勵及紀錄；自行刪除所有項目後，重新整理也不會恢復預設項目。

## 2026 年 11 月文件集星表

`november-plan.js` 逐日收錄使用者提供的 2026 年 11 月獎勵表：30 天、21 種任務版本，每天合計 10 顆星。週五 9 個任務，「主動」為 2 顆；週六不含睡前項目；一般平日與週日含 21:40 前就寢的條件。首頁日期可切換 11 月各天；當下不在 11 月時，預設顯示 11/1。所有原文條件保留，依家長點選給星，不自動判斷完成。

舊瀏覽器首次載入此版會套用文件任務，保留餘額、歷史、既有兌換清單與自訂孩子姓名；原任務設定存於 `previousMissionConfig` 作為備份。每個瀏覽器只套用一次，之後管理項目所做的修改不會被刷新覆蓋。兌換項目採使用者另外提供的 7 項清單：20 顆睡前多選一本故事、40 顆多 20 分鐘遊戲／卡通、80 顆 200 元以內玩具、100 顆選餐點、150 顆 500 元以內玩具、200 顆選週末親子活動、300 顆 1000 元以內玩具。首次套用備份原兌換設定於 `previousRewardConfig`，不變更過往兌換紀錄與餘額。管理畫面顯示所有任務版本；新建任務會在所有日期顯示。
